# Czech translation sample

`babicka-cs.txt` contains the opening paragraphs of chapter I of **Babička** by
**Božena Němcová**, ending at a paragraph boundary below the API's 10,000-character
input limit. The original spelling and paragraph breaks are retained.

Source: NĚMCOVÁ, Božena. *Babička*. 7th edition. Praha: Česká grafická unie,
1924, chapter I, pp. 9–17.

Transcription: [Czech Wikisource, revision 284292](https://cs.wikisource.org/w/index.php?title=Babi%C4%8Dka/I&oldid=284292),
retrieved on 2026-10-09. Only the literary text is included, without website
navigation or editorial metadata.

Wikisource identifies this text as **PD old 70 (public domain)**. This literary
sample remains public domain; the project's GPL-3.0-or-later license applies to
the program code and does not impose additional restrictions on the sample.
